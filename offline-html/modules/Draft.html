Module Draft

Draft library for TheoTown

A draft can be considered a single "plugin object" like the template for a building.

This library contains functions and methods to access drafts and query basic information about them.

Multiple scripts can be attached to a single draft.

Usage:

    local d = Draft.getDraft('$park00')
print(d:getId())

append (json)
Adds a JSON code to the list of JSON codes that will be loaded by the game. Can only be called during the main call of the Lua script. That is, when the script's main body is called. Can be useful to generate JSON code dynamically.

Parameters:

  • json string A string containing the JSON code to load.

Usage:

    local json1 = [[
[
  {
    "id":"somerandoasdfjldjfkl1",
    "type":"script",
    "script":"function script:init() Debug.toast('Appending draft is working 1') end"
  }
]
]]
Draft.append(json1)

merge (json)
Merges the provided JSON object into the json object that is being loaded by the game right now. Can only be called during the main call of the Lua script. That is, when the script's main body is called. Can be useful to define JSON code dynamically for the current draft. Will only have an effect for attributes that were not read by the game, yet.

Parameters:

  • json string A string containing the JSON code to merge. Must be a JSON object.

Usage:

    local json = [[
  {
    "animation":[{"id":"3x2l_right_1","x":1,"y":2}]
  }
]]
Draft.merge(json)

draft:setFrameType (frameIndex, frameType)
Sets the frame type of a frame based on its index (starting with 1). The frame type is a 0-255 integer number that can be accessed from within the shader. The values 0-64 can be considered as reserved by the game. You should only use frame types that are either defined by the game or were previously allocated using Drawing.allocateFrameType(). Use the frameType value 0 to indicate that the frame has no specific type (in this case Drawing.setFrameType will take precedence).

Parameters:

  • frameIndex int
  • frameType int The frame type to set.

Returns:

    int The previously set frame type of the frame.

  • frame int New preview frame.
draft:setVisible (state)
Sets the visibility state of the draft (corresponds to negated hidden attribute in json). For buildings, the visibility state determines whether they appear in the toolbar. You may have to call City.rebuildUI() for the change to become visible in the toolbar.

Parameters:

  • state bool The new visibility state.
