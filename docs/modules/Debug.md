# Debug

Functions for debugging. Don't forget to remove/comment out your debug functions before publishing your script/plugin. Usage: Debug.log('Hello World', 'Multiple arguments') Debug.toast('I am a toast') Debug.info('I am displayed in debug overlay')

Official source: <https://doc.theotown.com/modules/Debug.html>

## Module Functions

### `info (message1[, message2[, message3[, ...]]])`

Logs a message into the debug overlay of the game.

### `log (message1[, message2[, message3[, ...]]])`

Logs a message to the script's internal log.

### `toast (message1[, message2[, message3[, ...]]])`

Shows the specified message as a toast overlay.
